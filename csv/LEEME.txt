=============================================
 CATALOGO BTA 2.0 - ESTRUCTURA DE DATOS
=============================================

Este catálogo ha sido generado automáticamente a partir 
de la base de datos 'cat_bta20'. Contiene tanto los 
metadatos (atributos, valores, temas, objetos geográficos, 
etc.) como las páginas HTML resultantes, junto con los 
archivos CSV que representan fielmente las tablas del 
modelo de datos.

---------------------------------------------
🗂️ TABLAS INCLUIDAS (csv)
---------------------------------------------

Cada tabla se distribuye en un archivo CSV independiente, 
con los siguientes criterios:

  • Codificación: UTF-8-sig 
  • Separador: punto y coma ( ; )  
  • Primera línea: cabecera con los nombres de las columnas  
  • Una fila por registro  

---------------------------------------------
📑 NOTAS IMPORTANTES
---------------------------------------------
Las tablas ver_objXatr_BTA20 y ver_objXatrXvalor_BTA20 no forman
parte del modelo relacional original, sino que se generan a
posteriori para facilitar al usuario una consulta unificada de
la información. Funcionan como "tablas de cruce" que combinan
datos procedentes de varias tablas del catálogo, de modo que es
posible ver la relación entre objetos, atributos y valores de un
solo vistazo. Estas tablas no incluyen los atributos comunes de
los objetos.
